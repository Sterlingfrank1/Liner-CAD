# Liner-CAD v0.1.3 发布说明

- 发布版本号：`0.1.3`（对应 tag `v0.1.3`，见 `pyproject.toml` 与 `uv.lock`）
- 基线版本：`v0.1.2`（`74d4b84`）
- 里程碑文档与交接记录：[v0.1.3 HANDOVER](../milestones/v0.1.3/HANDOVER.md) · [v0.1.3-REQ](../milestones/v0.1.3/v0.1.3-REQ.md) · [v0.1.3-SPEC](../milestones/v0.1.3/v0.1.3-SPEC.md) · [v0.1.3-CARDS](../milestones/v0.1.3/v0.1.3-CARDS.md)

## 范围

`v0.1.3` 围绕两件事收口：**让 Viewer 真正进入首图与交互编辑主流程（R1–R8）**、**让一张满意的图纸沉淀成项目级可复跑参数模板（R9–R12）**，并补齐 **表格 / 标题栏样式脚本化与 PNG Logo（R13–R15）**：

1. **Viewer 流程闭环与清理（PR-1 `#164`/`#165` + 跟进卡 C1b `#166`/`#167`）**：
   - `lcad build` / `lcad edit` 新增 `--ensure-viewer` 与 `--no-viewer`，`--ensure-viewer` 显式覆盖 `LCAD_NO_VIEW` 与 `CI`，后台静默启动守护进程并在 JSON 返回 `viewer.url`；`lcad view` 默认端口被占用时自动回退到空闲端口（显式 `--port` 被占仍报错 `viewer_bind`）。
   - 左右面板支持拖拽调宽（`localStorage` 持久化与双击复位）、双侧折叠及 `<=1100` / `<=820` 窄屏响应式适配；移除底部冗余 `#hint` 说明条（C1b `#166`/`#167`）。
   - 画布交互调整为左键两态框选（L→R 蓝实线全包含 / R→L 绿虚线相交）、右键/中键/`Space` 平移与右键菜单抑制；检查器文案改为「已选中 N 个元素」（不再出现 `selection.json` 字样，保留 `Ctrl+Alt+C`）。
   - `Viewer.select` 默认截断上限 `50`（`LCAD_SELECTION_CAP`），`lcad context "@sel"` 超过 10 个元素时返回摘要（保留 `items: []` 与 `summary: true`）。
   - 标题栏全部 16 个字段单元格（含空字段如 `T.title.company`）生成 `cell_box` 与命中矩形并支持点选引用。
   - 新增 `GET /api/download?fmt=dxf|pdf|png[&preview=1]` 无副作用下载当前产物（不影响工作区 git 状态 / tag / `.linercad/build`）；含内部外部图片资源的 DXF 自动打包为 `.zip`（`X-LCAD-Archive: zip`），越界路径拒绝返回 `409`。
2. **项目级模板与保存前自检（PR-2 `#170`/`#171`）**：
   - 新增 `src/linercad/project.py` 与 `linercad.project.toml` 标记：项目根按 `--project` > `LCAD_PROJECT_ROOT` > 向上找 marker（跳过图纸自身 `.git`，遇祖先 `.git` 查完再停）> `cwd.parent` / `cwd` 解析，严守不建在图纸目录内；`init --from` 按 **项目 > 用户 > 内置范例** 查找。
   - `lcad template save` 支持 `--scope project|user`、`--project` 与 `--tag`（`--tag` 仅写入 `template.json`，不在用户项目执行 `git commit`/`git tag`）；自动按语义 op 类型与 ID 前缀过滤固化为 `baseline.actions.jsonl` 并复制图纸内图片至 `assets/`（越界图片拒绝保存）。
   - `init --from` 合并基线修订为 `e0` 并校验 `model_hash`，同时拒绝 `lcad undo e0`。
   - 保存前自动在隔离临时目录执行有界参数（非空且 `min != max`）的 min/max 边界探测（上限 16 次，支持 `--force-probe-fail` 与 `--no-probe`），并在 `template list` / `init --from` 返回 `trust` 与外部来源提示。
3. **表格样式脚本化与标题栏 Logo（PR-3 `#168`/`#169`）**：
   - `Cell.set()`（`text`、`text_height`/`font_size`、`align`、`wrap`、`bold`）与 `Table.set()`（`title`、`cols`/`col_widths`、`row_height`、`text_height`/`font_size`、`wrap`、`border_width`）以及 `d.table(..., border_width=...)` 打通 DXF / SVG / PNG / PDF 四端同步样式控制。
   - `rules.py` 新增 `title_style_gb`（`GB/T 10609.1-2008`）与 `table_style_gb`（`GB/T 14691-1993`）警告规则，并将 `table_overflow` 覆盖到标题栏单元格（按实际边框网格校核）。
   - 新增 `d.logo(cell, path, width, height)`，支持标题栏格内嵌 PNG Logo、四路同步导出（SVG `<image>`、DXF `IMAGEDEF`/`IMAGE`、PNG/PDF）、`lcad export` 自动拷贝 `assets/` 并触发 `logo_external_ref` 提示。
4. **版本收口与发布准备（PR-4 / R16 `#172`）**：
   - 升级版本号至 `0.1.3`（`pyproject.toml`、`uv.lock`），同步 `docs/releases/v0.1.3.md`、`docs/milestones/v0.1.3/HANDOVER.md`、`docs/ROADMAP.md`、`README.md` 与 `docs/milestones/v0.1.3/PROGRESS.md`，并完成全局安装与 `scripts/release.py 0.1.3` 验证。

## 安装

```bash
git clone https://github.com/Sterlingfrank1/Liner-CAD && cd Liner-CAD
uv tool install --force --reinstall --no-cache .
# 如需 3D 模型投影能力：
uv tool install --force --reinstall --no-cache --with build123d .
```

任意目录验证全局 CLI：

```bash
lcad --version
# {"ok": true, "version": "0.1.3"}
```

升级 Skill（如已安装 DSH skill，需重新覆盖）：

```bash
lcad skill install --target dsh
```

发布（仅在 PR-4 合并且 `main` CI 四项全绿后执行）：

```powershell
uv run python scripts/release.py 0.1.3 --dry-run
uv run python scripts/release.py 0.1.3
gh release view v0.1.3
```

## 已知缺口

- **模板与导入范围（按需求刻意不做，见 `v0.1.3-REQ.md` §4）**：不支持 `kind: sheet|drawing` 双形态；不做参考 DXF/PDF 自动逆向建模板（PDF 解析/OCR）；暂不做将 `baseline.actions.jsonl` 折叠进单文件 `drawing.py` 的 codegen（B 方案推迟到 `v0.1.4` 及以后）；`d.logo()` 仅支持 PNG，不支持矢量 Logo。
- **标题栏与网格交互边界**：可点选单元格聚焦于全部 16 个语义字段格与参数表格单元格（`T.params.<r>.<c>`），装饰性表头/行列边框线不单独切格与分配语义 ID。
- **Viewer 适用边界**：`lcad view` 仍仅面向本机单用户 `127.0.0.1` 回环访问，不做远程多用户鉴权。
- **既有转 v0.2 事项**：`#145`（全剖端面线贯通通孔）、`#146`（形位公差符号渲染）、`#147`（V1 发现汇总）及 STEP/PMI、尺寸排布精细优化继续留在 `v0.2` 轨道。

## 与 v0.1.2 的差异

- `pyproject.toml` 与 `uv.lock` 版本由 `0.1.2` 升至 `0.1.3`。
- Viewer 补齐 `--ensure-viewer` 优先级、`--no-viewer`、默认端口自动回退、面板拖拽折叠、左键两态框选、选择集 50 截断与 `@sel` 摘要、标题栏 16 格点选、无副作用下载，并删除底部 `#hint` 条。
- 模板系统由单用户目录扩展为项目级（`linercad.project.toml`）> 用户 > 范例优先级，新增语义基线 `baseline.actions.jsonl` 与保存前有界参数探测及来源信任提示。
- 样式与质检新增 `Cell.set()` / `Table.set()` 样式字段、`title_style_gb` / `table_style_gb` / 标题栏 `table_overflow` 规则及 `d.logo()` 标题栏 PNG Logo 四端同步导出。
