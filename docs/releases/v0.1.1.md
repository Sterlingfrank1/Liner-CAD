# Liner-CAD v0.1.1 发布说明

2026-11-23 · tag `v0.1.1`（tag 与 GitHub Release 由 supervisor 复核后在 main 上打）· 范围：`docs/releases/v0.1.0.md` 的“已知缺口”与 `docs/releases/v0.1.0-review.md` 的全部 v0.1.1 候选（用户 2026-11-14 决策）。逐卡清单、验证方式与遗留见 [HANDOVER](../milestones/v0.1.1/HANDOVER.md)，计划见 [PLAN](../milestones/v0.1.1/PLAN.md)。

Liner-CAD 是给 Coding Agent 用的通用 2D 工程图 harness（包 `linercad`，命令行 `lcad`）。它本身不是 Agent，内部不调 LLM。v0.1.1 的主线：先把“画得好不好”变成可比较、可回归的数字（评测分族向量与 baseline 门禁、规则变异、expect、形位公差条款覆盖、排布分数、DXF 导入两把尺、迭代速度 P 指标），再按数字修出图与导入（放射引线、多层尺寸、序号、明细栏、螺纹啮合、局部放大）、Viewer 六条界面缺口，以及迭代提速三件事（`edit --dry-run`、用户参数化模板、首次出图自动打开 Viewer + 选择同步到对话）。

## 范围

- 覆盖矩阵关闭：v0.1.0 发布说明“已知缺口”中的出图 6 项（D1–D3、D5–D7）、3D 投影边命名（D4）、DXF 导入 4 项（C1–C4）、跨 Agent 措辞（F1）、资源库 4 项（A1–A4）；v0.1.0 人工评审转 v0.1.1 的评测指标方案（E1–E7）、Viewer 界面 6 项（B1–B6）与 B7、以及 2026-11-13 试用后的三项（H2/H3/H4）、`edit --dry-run`（H1）、迭代速度（E7）。卡片共 33 张（issue #73–#102 去掉已随 PR #69 关闭的 A1/A3、#104–#108），逐卡去向见 HANDOVER §3。
- 明确不在 v0.1.1：3D 来源的阶梯剖 / 旋转剖 / 移出断面（U1 → v0.2）；标题栏 GB/T 10609.1 图 2 与 GB/T 14692 投影符号原文对照；GB/T 1095-2003 松联结 H9/D10、36×20 以上行、(d−t1)/(d+t2) 符号约定；ISO 5459 原文；Viewer 令牌加固；STEP AP242 语义 PMI；大样本评测（均为 v0.2 方向，见 `docs/ROADMAP.md` §6）。

## 安装

```bash
git clone https://github.com/Sterlingfrank1/Liner-CAD && cd Liner-CAD
uv sync                 # 核心依赖：ezdxf、matplotlib
uv sync --extra 3d      # 可选：3D 来源与装配图（build123d）
uv run lcad skill install --target claude --dir <Agent 工作目录>   # 或 codex / opencode / generic
```

Python ≥ 3.11。v0.1.1 不新增核心依赖，3D 仍是可选 extra。

## 与 v0.1.0 的差异

- **新增命令 / 接口：** `lcad edit --dry-run`；`lcad template save / list` 与 `lcad init --from <用户模板> --set`；`lcad build` / `edit` 的 JSON 带 `viewer: {url, opened}`；`lcad context "@sel"` 的选择新鲜度校验（`selection_stale`）；`lcad diff` 输出视图平移归并；`lcad inspect` 报告识别到的图框 / 标题栏。

- **工具链：** 发布脚本 `scripts/release.py` 与 `docs/RELEASING.md`（版本收尾检查单、annotated tag、GitHub Release）；tag 受 `protect-version-tags` ruleset 保护。
- **依赖：** 核心依赖仍为 ezdxf + matplotlib，3D 仍为可选 `linercad[3d]`；无新增核心依赖。
