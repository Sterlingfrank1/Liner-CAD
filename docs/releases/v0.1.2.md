# Liner-CAD v0.1.2 发布说明

2026-11-25 · 计划 [PLAN](../milestones/v0.1.2/PLAN.md) · 交接 [HANDOVER](../milestones/v0.1.2/HANDOVER.md) · 证据 [evidence/](../milestones/v0.1.2/evidence/)（tag `v0.1.2` 与 GitHub Release 由用户在 `main` 合并后执行 `uv run python scripts/release.py 0.1.2` 创建）

Liner-CAD 是给 Coding Agent 用的通用 2D 工程图 Harness 层（包 `linercad`，命令行 `lcad`）。`v0.1.2` 围绕 **“一次请求 = 一次达标交付”** 推进三件事与一次端到端计时复跑：全局安装 + `lcad skill install --target dsh`（C1）、`lcad build --png` / `lcad edit --png` 单事务出图（C2）、`d.table(...)` 语义参数表（C3），并在隔离临时图纸仓库用“零源码读取 + 批量修改”工作流重跑行星齿轮基准场景（V1）。

## 安装

Python ≥ 3.11。推荐全局安装后在任意图纸目录直接运行 `lcad`，无需在图纸仓库内 `uv run`：

```bash
git clone https://github.com/Sterlingfrank1/Liner-CAD && cd Liner-CAD
uv tool install --force .                      # 全局安装 lcad（3D 来源可加：--with build123d）
lcad --version                                 # 任意目录（如 %TEMP%）验证版本为 0.1.2
lcad skill install --target dsh                # 全局安装 DSH skill（~/.agents/skills/linercad/SKILL.md）
# 也可装进单个 Agent 工作目录：lcad skill install --target claude|codex|opencode|generic --dir <目录>
```

开发期在源码仓库内验证与运行评测可使用 `uv sync --extra 3d` 配合 `uv run ...`。

## 已知缺口

- **v0.1.3 摩擦点与同 harness 校准（[#156](https://github.com/Sterlingfrank1/Liner-CAD/issues/156)）：** ① `lcad skill --help` 返回 `usage: unrecognized arguments: --help`（子命令未注册 help）；② `d["G.cyl_bore"].set(target=...)` 错误提示应明确列出可写属性与只读限制；③ `d.q.lines().near(...)` 多命中时应在 `message`/`candidates` 按距离列出候选元素。V1 的 DSH 同 harness 校准复跑与分阶段数字门槛重定亦转 **v0.1.3**。
- **`d.table` v1 边界：** 不支持合并单元格 / 跨页表；`table_overflow` 挂在 `clause_status = "design"`（`DESIGN §4.2`），未编造字体标准条款号；多张移动后互叠的无标题表仅靠格间文字碰撞或用户调整避让。
- **v0.1.1 遗留 / v0.2 方向：** 全局安装后需重装才反映开发期源码改动；v0.1.1 登记的 #145 / #146 / #147、标准原文未核项及 38 条排布 known-debt 与 `v0.1.1` 发布说明一致。

## 与 v0.1.1 的差异

- **新增能力：** `lcad skill install --target dsh`（DSH 全局 skill 安装）；`lcad build --png` 与 `lcad edit --png`（成功事务直接出 PNG）；`d.table(...)` 语义参数表、`d.q.tables()` / `d.q.cells(...)`、`table_overflow` 检查、`T.title.*` 增加 `table="title"` facet、SVG/Viewer 语义单元格点选（含空单元格热区）。
- **评测与规则库：** `src/linercad/res/catalog.toml` 新增 `table_overflow`（37 → 38 规则），`evals/mutate.py` 新增 `_fx_table` / `m_table_overflow`（39 → 41 变异，检出率保持 1.0）。
- **文档与交付流：** `SKILL.md` / `pages/api.md` 新增交付轮与批量修改纪律、`d.table` 说明及 `d.template` 坐标示例限定；新增 `docs/milestones/v0.1.2/evidence/` 复跑证据集。
