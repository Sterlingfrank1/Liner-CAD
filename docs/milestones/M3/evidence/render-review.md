## 逐条处理

| 意见 | 处理 |
|---|---|
| 虎钳相邻零件剖面线同向同距 | **成立，已修**：零件间留了配合间隙，接触判定 ≤ 0.01 mm 认为不相邻；改为 ≤ 0.5 mm（`assembly.NEAR`），加回归测试；虎钳五个剖面区现在 45° / 135° / 135°·1.5 交替 |
| 相邻零件剖面线“方向必须不同” | 不成立：GB/T 4457.5 / 4458.6 允许方向相反**或**间隔不同；我们用两者 |
| gear_cover 主视全剖缺剖切符号与 A–A | 不成立：沿对称面的全剖、视图按投影关系配置时可省标注（GB/T 4458.6） |
| 尺寸交叉拥挤、引线斜穿视图（pump_body、bearing_support、装配） | 成立，**未修**：布局引擎对放射状直径引线和多层尺寸的避让仍弱；列入已知缺口（v0.2 布局与出图评审的重点） |
| 序号引线挨得近、未排成整齐的行列（bearing 6/7、vise 3/4） | 部分成立：引线已保证不交叉，但没有最小间距与对齐；列入已知缺口 |
| 装配图无螺纹规定画法（螺杆与螺套啮合） | 成立，未做：标准件与螺纹按大径简化建模（SPEC 已声明）；列入已知缺口 |
| 千斤顶顶部细节难辨、缺局部放大 | 成立：3D 来源与装配视图目前不能出局部放大；用 2D `d.detail` 补的路子未接到 3D 投影上 |
| vise 明细栏代号重复（两块钳口板） | 成立：同一零件两处安装应合并为一行“数量 2”；明细栏没有相同零件合并，列入已知缺口 |
| 评测图（Claude 装配）分数最低 | 如实：该图由 Agent 在 4 轮内画出，视图与尺寸选择是 Agent 的；harness 的缺陷（第二个螺栓丢失）已在 #66 修复 |
