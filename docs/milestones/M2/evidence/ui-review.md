# Viewer UI 评审（9 张截图，仅按所见判断）

说明：多数截图为 800x450，整图适配画布后图内文字、选中高亮都很小，下列判断以此为前提。只有 flange-slider-preview-L49 是放大图。

## 评分（1-5）
| 维度 | 分 | 一句话 |
|---|---|---|
| 布局 | 3 | 三栏加状态栏结构清楚，但画布上下有大块空灰带，两侧栏文字小而密 |
| 选中与着色 | 3 | 蓝色选中能辨认（flange-r2 最明显），橙色警告和蓝色在小尺寸下几乎分不开 |
| 检查器 | 3 | 字段齐全、有来源链接和“修改于 eN”，但原始 JSON 外露，警告没有颜色强调 |
| 参数面板 | 4 | 滑块、数值、红色违规提示、改动高亮都有；违规后写回按钮状态和范围提示不清 |
| 状态栏 | 3 | eN、警告数、用户原话都有，但字号很小，对比弱，原话被截断 |
| 整体可用性 | 3 | 主流程通；高亮和信息层级偏弱，高密度图纸上不易定位 |

## 问题清单（按严重度）
1. flange-slider-rule-violation.jpg：Dh=120 违反规则 Dh<pcd-dh 时，参数名、数值、滑块变红，红字消息在面板底部，字很小，离滑块很远。画布上没有对应的红色标记，用户看不出是图上哪处受影响。
2. flange-slider-rule-violation.jpg：违规状态下“写回源码”灰着（不可用），也没说明为什么不可用、怎么恢复。拖动时出现的“写回源码”小按钮夹在滑块之间（见 L49 放大图），挤占行距，和底部那个主按钮重复。
3. shaft-r2 / flange-r2：状态是 warn，检查器里“状态 warn”只是普通黑字，没有橙色，要读到下方才看到 overlap 提示。警告块的橙色左边线很细，灰色的标准号 GB/T 4458.4-2003 对比度低。
4. flange-r2：tolerance 直接显示原始 JSON（{"kind":"fit","code":"H8",...}），在窄栏里折行、被截断（“envelope”“aise”），是调试输出，不是给人看的公差。
5. shaft-r2 / flange-r2 / shaft-r3：警告元素用橙色、选中用蓝色，在图纸细线和密集标注里小尺寸下难辨，选中元素本身没有加粗或光晕。shaft-r1-selected 里选中的 D.L 在画布上基本看不出来。
6. 所有截图：画布上下各有约 40px 和更多的空灰带，图纸整页缩放后标注文字只有几个像素。初始视图没有按内容适配放大，用户一进来就要自己缩放。底部“滚轮缩放…”提示字极小，对比低。
7. 状态栏（各图）：深色条里小字，“e2 · 2 个警告 · “我选中的…””被截断，看不到完整用户原话；警告数没有颜色区分（0 个和 2 个同样的灰白）。
8. flange-slider-preview-L49：预览中显示“预览 135.5 ms”，但画布上的变化（L=49 时的蓝色/橙色线）没有标明是预览还是已提交，也没有“松手后提交”的提示，用户分不清当前是不是真实状态。
9. shaft-r1-selected / flange-r0：未选中时检查器只有一行“点选图上的元素（Ctrl 多选）”，其余整栏空白；已有选中时标题“1 个已写入 selection.json”的含义对人不直观。
10. 参数面板（各图）：参数名中文加符号（如“退刀槽底径 dg”）较长，左栏只有约 120px 宽，单位和数值右对齐尚可，但滑块没有显示范围或刻度，不知道可调多大。

## 做得好的
- 参数、检查器、状态栏的信息和设计一致：eN 编号、警告数、用户原话、“修改于 eN”都能看到。
- 违规滑块变红并给出规则原文和当前数值（Dh=120, pcd=90, dh=11），符合“失败时给出原因和数值”。
- 检查器含来源文件行号链接、引用、复制 @ID 按钮。
