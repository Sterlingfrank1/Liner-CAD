## 2. 设计

### 2.1 Viewer 生命周期（PR-1 / R1）

| 条件 | 起守护进程 | 开浏览器 | JSON `viewer` |
|---|---|---|---|
| 默认 | 是 | 是（首次） | `{url,pid,started,opened,reused}` |
| `LCAD_NO_VIEW=1` | 否 | 否 | 无该键 |
| `CI=1` | 否 | 否 | 无该键 |
| `--ensure-viewer` | 是 | 否 | 同上 |
| `LCAD_NO_VIEW=1` + `--ensure-viewer` | **是** | 否 | 同上 |
| `CI=1` + `--ensure-viewer` | **是**（显式覆盖 CI） | 否 | 同上 |
| `--no-viewer` / `LCAD_NO_VIEWER=1` | 否 | 否 | 无该键 |

- `_suppressed()` 改为显式判定（`force_off` / `ensure`），env 不得无条件优先。
- `--no-viewer` 与 `--ensure-viewer` 同时给 → 用法错误。
- `--ensure-viewer` **同时覆盖** `LCAD_NO_VIEW` 与 `CI`，否则该行为在 GitHub Actions（自带 `CI=1`）里无法测试。
- `autostart()` 主体不动（锁、`--port 0`、状态文件、失败清理）。

### 2.2 端口回退（PR-1 / R2）

`serve()` 在 `_start_server()` 抛 `OSError`（10048/EADDRINUSE）时：
- **未显式给 `--port`**（`cli.py` 的默认值改为哨兵 `None`，再解析为 8765）→ 以 `port=0` 重试一次，写入真实端口；
- **显式给了 `--port 9999`** → 直接报错退出（`{ok:false,error:{code:"viewer_bind",...}}`，退出码 1），不静默换端口。
- 重试再失败同样报错。

### 2.3 面板与文案（PR-1 / R3、R6）

- `viewer.css`：`#app` 用 `--left-w` / `--right-w` 变量，替换固定 `250px 1fr 320px`。
- `viewer.js`：两处分隔条 `pointerdown` 拖拽（`min 180 / max 520`），`dblclick` 复位；宽度写 `localStorage`（`lcad.leftW` / `lcad.rightW`）；折叠按钮带 `aria-expanded`；`≤1100` 默认收右、`≤820` 双收。
- 状态文案：`已选中 N 个元素`（去掉 `selection.json` 与 `Ctrl+Alt+C` 字样），保留处理器。

### 2.4 框选与选择集（PR-1 / R4、R5）

状态机：
1. `mousedown`：左键 → 选择候选；右键/中键 → 平移；`Space+左键` → 平移（可选，若做则 `preventDefault`）。
2. 抬起位移 < 4px → 单击（`Ctrl` 切换选中）；点击空白清空。
3. 位移 ≥ 4px → 框选；L→R 蓝实线（完全包含）、R→L 绿虚线（相交，容差 `0.75*sc`）。
4. 命中集合来自 `S.boxes`；**默认排除 `data-kind="table.cell"`**，`Ctrl+框选` 才包含并追加；`Shift+框选` 追加（不含量 cell）。
5. 抬起后一次性 `POST /api/select`；截断时状态栏"已选 N（共 M）"。
6. 右键位移 >4px 才抑制 contextmenu；中键拦 `auxclick`。

服务端：
- `LCAD_SELECTION_CAP`（默认 50；≤0 不限制，仅测试）。
- `/api/select` 截断并写 `selection.json` 新字段 `total/truncated/kinds`；响应 `{ok,count,total,truncated}`。
- `lcad context "@sel"`：`total ≤ 10` 现状；`> 10` 返回 `{ok,count,truncated,kinds,ids,items:[],summary:true,hint}`——**`items` 保留为空数组**，读 `resp["items"]` 的旧脚本不抛 KeyError。

### 2.6 下载端点（PR-1 / R8）

`GET /api/download?fmt=dxf|pdf|png[&preview=1]`（token + `_host_ok`）。
- 预览参数存在且 `preview=1` → `runtime.build(dir, params=..., dxf=True)`；否则按已提交状态构建（不写盘）。
- 写 `tempfile.mkdtemp(prefix="lcad-dl-")`，用 `render_png`/`render_pdf` 输出；`Content-Disposition` 附件；文件名 `<drawing_no|dir>-<edit>[-preview].<ext>`；`finally` 删临时目录。
- 禁止 `versions.export`；禁止写 `.linercad/build`、`drawing.py`、`drawing.actions.jsonl`、git。
- **外部图片**：构建产物若引用外部图片（Logo），`fmt=dxf` 返回 **`.zip`**（内含 `drawing.dxf` + 图片，保持相对路径）；无外部引用时仍返回单个 `.dxf`。响应头 `X-LCAD-Archive: zip|single` 明示。
- 前端用 `fetch(url, {headers:{"X-LCAD-Token":...}})` 取 blob 再触发下载（token 不进 URL）；非 2xx 时读 JSON 弹提示。
- 失败：构建失败 `409`，参数非法 `400`。

### 2.7 项目级模板（PR-2 / R9、R12）

**只有一种模板形态**（D4）：一个图纸程序 + 可选基线，没有 `kind`、没有 `init --sheet`。

**项目标记** `linercad.project.toml`：

```toml
version = 1
name = "raptor-project"
created = "2026-11-26T12:00:00+00:00"
[templates]
dir = "lcad-templates"
```

**解析顺序**（从明确到推断，绝不猜）：
1. `--project <root>`（显式，最高优先）；
2. 环境变量 `LCAD_PROJECT_ROOT`（skill 约定：Agent 把自己的**工作区根**传进来）；
3. 从 `cwd` 向上找最近的 `linercad.project.toml`：**跳过 `cwd` 自身的 `.git`**；每个祖先目录先查 marker，遇到含 `.git` 的目录**查完再停**；到盘根停；
4. 都没找到时（仅 `--scope project` 会创建）：
   - `cwd` 是图纸目录（存在 `drawing.py` 或 `.linercad/`）→ 用 **`cwd.parent`**；
   - 否则用 `cwd`；
   - 解析结果是盘根或 `cwd` 的祖先中没有可写目录 → 报错，要求 `--project`。

**铁律**：**永不把 `linercad.project.toml` / `lcad-templates/` 建在图纸目录内部**。创建前打印将写入的两个绝对路径；`--dry-run` 只打印不写。

**目录**：`<root>/lcad-templates/<name>/`（普通目录、无嵌套 git）。

**命令**：
- `lcad template save <name> [--scope project|user] [--project <root>] [--tag <t>] [--dry-run] [--no-probe] [--force-probe-fail]`
- `lcad template list`：加 `scope` / `tag` / `path` / 参数数 / 创建时间（**没有 kind**）。
- `lcad init <dir> --from <name> --set ...`：名字解析 **项目 > 用户 > 范例**；输出带 `template:{scope,tag,path,trust}`。
- **信任**：`template.json.source` 记录创建源；`source` 不在当前项目 → `trust:"external"` + 文案"模板含可执行 drawing.py，确认后再用"。

**tag 语义（D9）**：`--tag` 只写进 `template.json`，用于 `list`/`init` 输出与人工识别；**不是 git tag**。模板落在用户自己的图纸项目里，`lcad` 不 commit、不打 tag，与 Liner-CAD 开发仓的发布 tag 无关。

**空图框/标准图幅怎么办**：不搞特殊类型。用户要"只有图框的模板"，就让 AI 写一个只含 `Drawing(sheet=..., overlay=...)` + `d.title(...)` 的 `drawing.py` 保存即可。

### 2.8 基线重放（PR-2 / R10）

模板包：

```
<name>/
  template.json
  drawing.py
  baseline.actions.jsonl   # 可选：无迭代时为空/不存在
  model.py                 # 可选
  templates/               # 可选
```

**方案 A（已定）**：两文件包；v0.1.3 不做 `--squash` 单文件合并（B 方案推迟到 v0.1.4+）。包内两文件是一个单元。

**保存**：
1. 读 `drawing.actions.jsonl`，按两条规则保留：
   - **按 op 类型**：`accept`、`general_tol`、`rough_default` 一律保留（策略/元数据，无几何 ID）；
   - **按目标 ID 前缀**：`D. / N. / G. / R. / DT. / T. / A. / B. / K. / V.` 保留（覆盖尺寸、注释、形位公差、粗糙度、基准、表格/标题栏、装配、明细、尺寸链、视图）；
   - 其余（`E.* / C.* / F.* / X.* / H.* / S.*`）丢弃，统计数量并在结果里给前 5 条示例。
   - 注意：`notes.tech` 的 id 是 `N.tech.<k>`；`accept` 的 id 是被放行元素或规则目标。
   - 若某条保留的 op 在**参数**里引用了 `E.*`，过滤阶段发现不了，交给 `2.9` 自检标记。
2. `edit` 改写为 `"e0"`，保留 `_line`。
3. 算 `model_hash` 写 `template.json`（定义见 §3）。
4. 若 `drawing.py` 引用外部图片（`d.logo(path=...)`）：要求路径在**图纸目录内**（如 `assets/logo.png`），保存时把 `assets/`（或引用文件）一并复制进模板包；路径指向目录外 → **拒绝保存**并给出绝对路径。
5. 跑自检（见 §2.9），失败拒绝（`--force-probe-fail` 可强制）。

**实例化**：
1. 复制 `drawing.py`、`model.py`、`templates/`。
2. `baseline.actions.jsonl` 原样写成新目录的 `drawing.actions.jsonl`（D3：不加第二日志）。
3. `build` 必须 0 error；参数未改时 `model_hash` 必须一致，否则失败回滚；改过参数时允许不一致，但输出 `baseline_warnings`（语义 stale 列表）。
4. 一次提交：有 tag → `e0 · init --from <name>@<tag>`；无 tag → `e0 · init --from <name>`（**不留尾随 `@`**）。

**undo/diff**：`undo e0` 必须拒绝（补测试锁住）；`lcad log`/`diff` 正常。

### 2.9 保存前自检（PR-2 / R11）

- 对每个 `Param`：只对**非 None 且 `min != max`** 的边界构建（`min` 或 `max` 缺省时跳过该侧）；每次重放基线；总构建数 ≤ 16，超出报 `skipped`。
- 失败条件：构建崩溃 / `errors>0` / `Param.rule` 违反 / **语义 ID** 的 stale。
- 不失败：`E.*` stale、普通布局 warning。
- 输出 `probe:{builds,failed,stale_semantic,skipped}` 写进 `template.json`。

### 2.10 样式 API（PR-3 / R13、R14）

- 单元格（`table.cell`，含 `T.title.*`）：`set(text_height=<mm>, align="left|center|right", wrap=bool, bold=bool)`；
- 表格（`T.<name>`）：`set(cols=[...], row_height=<mm>, border_width=<mm>)`；
- **命名与现有 API 对齐**：以 `d.table(cols=..., text_height=...)` 的既有参数名为主；`font_size` / `col_widths` 作为**别名**接受（内部映射到 `text_height` / `cols`），文档只推一种写法，避免 Agent 记混。
- 标题栏文本仍用 `d.title(...)`；样式走单元格 `set()`。
- GB 守护：标题栏/表格字号越界 `[2.5,5.0]` mm 或与标准档不一致 → `title_style_gb` / `table_style_gb`（warning）。
- 渲染链路：`layout` 行高、`dxfout` 文字、`svgout` `font-size`、PNG/PDF（复用 DXF）共用同一覆盖值。
- `table_overflow` 扩到标题栏 16 格。

### 2.11 Logo（PR-3 / R15）

- `d.logo(cell="company", path="logo.png", width=<mm>, height=<mm>, align="center")`（只 PNG）。
- DXF：`IMAGE`+`IMAGEDEF` 外部引用；`export`/下载时把图片复制到产物同目录并在 `files` 里列出；`lcad check` 新增 `logo_external_ref`（warning：DXF 不自包含）。
- SVG/PNG/PDF 内嵌绘制，同一 `box` 计算；四路外接矩形偏差 ≤ 0.2 mm；缺图 → 构建失败并给路径。

## 3. 文件格式

`template.json`（只增不改）：

```json
{
  "schema": 2,
  "name": "raptor-v3-ext",
  "tag": "r1",
  "description": "",
  "created": "2026-11-26T12:00:00+00:00",
  "source": {"dir": "C:/.../raptor_v3_drawing", "created": "..."},
  "files": ["drawing.py", "baseline.actions.jsonl"],
  "params": [{"name": "L", "value": 3550, "min": 3200, "max": 3900}],
  "model_hash": "sha256:...",
  "probe": {"builds": 8, "failed": [], "skipped": []}
}
```

`model_hash`：对 `model.json` 规范化后 sha256——取 `elements[].{id,kind,intent,resolved,refs,status}`（按 id 排序），排除 `edit/history/src/issues` 与时间戳，浮点保留 3 位。
