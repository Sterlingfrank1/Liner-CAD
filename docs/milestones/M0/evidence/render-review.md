## 评审指出的问题与处理

| 问题 | 处理 |
|---|---|
| 法兰端面视图的凸台圆 Φ60 应为虚线（凸台在盘后） | **已改**（范例 `role="hidden"`），见 `flange.png` |
| 技术要求与图形不符（支架“未注圆角 R2”、法兰“未注倒角 C1”） | **已改** |
| 支架 Φ20 孔缺水平定位尺寸 | **已加** `D.xh`（定位尺寸，基准为左端面） |
| 标题栏应为 140×32 | 不改：GB/T 10609.1 标题栏外形为 180×56；评审所说 140×32 是教学用简化标题栏 |
| 标题栏 / 技术要求中文“字高 2.39 mm”太小 | 不改：2.39 是 DXF 大写字母高；中文字身按实测缩放后为 3.5 mm（SPEC §2），符合 GB/T 14691 |
| PNG 中粗细线对比不明显 | 记为已知缺口：DXF 线宽正确（0.5 / 0.25），渲染按绝对线宽在 150 dpi 下对比弱；M1 视需要调整渲染线宽比例 |
| 轴的 Φ 尺寸文字位置不一致（Φ36 在内，其它移到轮廓外） | 记为已知缺口：属引擎按冲突选位的结果（Φ25/Φ30 在轴线上方放不下）；M1 布局评测时再定统一规则 |
| “EQS” 应写“均布” | 不改：GB/T 16675.2 采用 EQS 作为均布缩写 |
| 无表面粗糙度 | M1 范围（BRIEF §2 不做） |

修正后三张图见 `shaft.png`、`flange.png`、`bracket.png`（由干净 clone 的 `lcad init --from` + `lcad render` 生成，零 warning）。**最终人工评审待用户进行**（HANDOVER §6）。
