# 带肩衬套

## 功能
压入箱体座孔的滑动轴承衬套：体部外圆与座孔过盈配合，肩靠在箱体端面上轴向定位，内孔与轴间隙配合。

## 形状与尺寸（mm，轴线水平，肩在左）
| 项目 | 尺寸 | 公差 |
|---|---|---|
| 总长 | 45 | |
| 肩 | 外径 Ø50，厚 6 | |
| 体部外径 | Ø40 | r6 |
| 内孔 | Ø32 | H7 |
| 倒角 | 体部右端外圆 C1；内孔两端 C1 | |

## 技术要求
- 以内孔轴线为基准 A：外圆对 A 的同轴度 0.03；肩的支承面对 A 的垂直度 0.02。
- 内孔 Ra 0.8（铰），外圆 Ra 1.6（磨），其余 Ra 6.3。
- 材料 ZCuSn10P1；压入座孔后精加工内孔；去除毛刺锐边；未注尺寸公差按 GB/T 1804-m。

## 图纸要求
- 一张 A3、2:1。半剖视主视图（上半剖开、下半画外形，轴线水平）。
- 标注全部尺寸（含倒角）、配合公差、形位公差、粗糙度、技术要求和标题栏。
