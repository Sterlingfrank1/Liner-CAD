# 花键轴

## 功能
变速机构的输入轴：左端为矩形花键，插入滑移齿轮的花键孔传递扭矩；两个 Ø30 轴颈装轴承；Ø38 轴肩给轴承轴向定位。

## 形状与尺寸（mm，轴线水平，花键端在左）
| 段（自左向右） | 尺寸 | 说明 |
|---|---|---|
| 花键段 | 矩形花键 6×23×26×6（轻系列，GB/T 1144），长 36 | 键齿对称于铅垂中心面（齿顶在正上、正下）；配合代号取标准推荐的滑动配合 |
| 左轴颈 | Ø30 k6，长 30 | |
| 轴肩 | Ø38，长 10 | |
| 右轴颈 | Ø30 k6，长 44 | 右端倒角 C1.5 |

总长 120。两端 A 型中心孔：花键端 A2.5/5.3，右端 A3.15/6.7（加工后保留）。

## 技术要求
- 两个 Ø30 轴颈的公共轴线为基准 A-B；花键外圆对 A-B 的径向圆跳动 0.03。
- 轴颈 Ra 0.8（磨），其余 Ra 6.3。
- 调质 28~32HRC，花键齿部高频淬火 48~53HRC；去除毛刺锐边；未注尺寸公差按 GB/T 1804-m。

## 图纸要求
- 一张 A3、1:1。主视图（轴线水平）表达花键、轴颈、轴肩、中心孔；再给花键端的端面视图，画出齿形。
- 标注全部尺寸（含倒角）、花键代号、配合公差、形位公差、粗糙度、技术要求和标题栏。
