# 泵轴

## 功能
小型离心泵的轴：左端 M16 外螺纹锁紧叶轮，两个 Ø20 轴颈装轴承，Ø26 轴肩给左轴承轴向定位，右端 Ø18 轴头装联轴器并用平键传扭。

## 形状与尺寸（mm，轴线水平，螺纹端在左）
| 段（自左向右） | 直径 | 长度 | 说明 |
|---|---|---|---|
| 螺纹段 | M16（粗牙），6g | 螺纹长 19.5，其后退刀槽宽 3.5、槽底 Ø13（GB/T 3：P = 2 时槽宽 ≥ 3.4，槽底 d − 3） | 左端倒角 C1，退刀槽与螺纹合计 23 |
| 左轴承位 | Ø20 k6 | 30 | |
| 轴肩 | Ø26 | 8 | |
| 右轴承位 | Ø20 k6 | 35 | |
| 轴头 | Ø18 k6 | 40 | 平键键槽（国标普通型）长 22，起点距台阶 4，朝向主视图观察者；右端倒角 C1 |

总长 136。两端面有 A 型中心孔 A2.5/5.3（加工后保留）。

## 技术要求
- 两个 Ø20 轴承位的公共轴线为基准 A-B；Ø18 轴头相对 A-B 的径向圆跳动 0.02。
- 轴承位 Ra 0.8（磨），轴头 Ra 1.6（磨），其余 Ra 6.3。
- 调质 217~255HBW；未注圆角 R0.5；未注尺寸公差按 GB/T 1804-m。

## 图纸要求
- 一张 A3、1:1。主视图表达外形、螺纹、退刀槽、键槽、中心孔。
- 键槽用移出断面表达并标注宽度和深度。
- 标注全部尺寸（含倒角）、配合公差、形位公差、粗糙度、技术要求和标题栏。
