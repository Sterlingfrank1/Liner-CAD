# 隔套

## 功能
装在轴上两个零件（如两个轴承）之间的隔套，只传递轴向压力，两端面必须平行，保证压紧时受力均匀。

## 形状与尺寸（mm，轴线水平）
| 项目 | 尺寸 | 公差 |
|---|---|---|
| 长度 | 28 | |
| 外径 | Ø42 | h9 |
| 内孔 | Ø30 | H9 |
| 倒角 | 外圆两端 C1；内孔两端 C1 | |

## 技术要求
- 以左端面为基准 A，右端面对 A 的平行度 0.02。
- 两个端面 Ra 1.6，其余 Ra 6.3。
- 材料 45；去除毛刺锐边；未注尺寸公差按 GB/T 1804-m。

## 图纸要求
- 一张 A3、2:1。全剖视主视图（轴线水平）。
- 标注全部尺寸（含倒角）、配合公差、形位公差、粗糙度、技术要求和标题栏。
