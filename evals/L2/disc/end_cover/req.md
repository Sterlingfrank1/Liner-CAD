# 端盖（HT200 铸件）

**用途**：盖在设备端面的孔口上，止口插入座孔定位，用 3 个 M8 螺钉从设备内侧旋入盖上的螺孔固定；中央阶梯孔穿过轴端并容纳密封件。

## 尺寸（mm）

| 项目 | 数值 | 说明 |
|---|---|---|
| 盖板外径 | Φ110 | |
| 盖板厚 | 16 | 带螺孔的外端面到盖板背面 |
| 总长 | 24 | 含止口，止口长 8 |
| 止口外径 | Φ70 h8 | 与座孔配合；止口端部外圆倒角 C1 |
| 中央孔 | Φ40 H7，深 18 | 从外端面起 |
| 沉孔 | Φ52，自止口端面深 6（到孔深 18 处） | |
| 螺孔 | 3×M8-6H，螺纹深 10，钻孔深 12.5（钻孔锥角 120°） | 盲孔，从外端面钻入；均布在 Φ85 圆周上，其中一个在正上方 |

## 要求

- 中央孔轴线为基准 A。止口外圆对 A 圆跳动 0.03；盖板背面（贴座面）对 A 垂直度 0.03；螺孔相对 A 位置度 Φ0.2。
- 粗糙度：中央孔 Ra1.6；止口外圆 Ra3.2；盖板背面 Ra3.2；其余 Ra12.5。
- 技术要求：铸件不得有砂眼、气孔、裂纹；未注倒角 C1；未注尺寸公差按 GB/T 1804-m。
- 图幅 A3，比例 1:1，标题栏：名称“端盖”，图号 LC-EC-01，材料 HT200。
