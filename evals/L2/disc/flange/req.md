# 法兰盘（HT200 铸件）

**用途**：安装在轴端，用 4 个螺栓固定到设备端面；中心孔与轴配合，凸台一侧伸出，起定位和加长配合长度的作用。

## 尺寸（mm）

| 项目 | 数值 | 说明 |
|---|---|---|
| 盘外径 | Φ120 | |
| 盘厚 | 15 | |
| 总长 | 40 | 含凸台 |
| 凸台外径 | Φ60 | 凸台在盘的一侧，伸出长度 25 |
| 中心孔 | Φ30 H7 | 通孔，与轴配合 |
| 螺栓孔 | 4×Φ12 | 通孔，均布在 Φ90 圆周上，其中一个在正上方 |
| 倒角 | 凸台端面外圆、孔口各 C1 | |

## 要求

- 孔轴线为基准 A。盘的安装端面（无凸台一侧）对 A 垂直度 0.03；盘外圆对 A 圆跳动 0.05；螺栓孔相对 A 位置度 Φ0.1。
- 粗糙度：中心孔 Ra1.6；安装端面 Ra3.2；其余 Ra12.5（铸造面）。
- 技术要求：铸件时效处理；铸件不得有砂眼、裂纹等缺陷；未注倒角 C1；未注尺寸公差按 GB/T 1804-m。
