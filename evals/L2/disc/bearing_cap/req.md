# 轴承透盖（HT200 铸件）

**用途**：封住轴承座端面，止口插入座孔定位，4 个螺栓固定；轴从中间孔穿出，孔里的矩形槽装毡圈密封。

## 尺寸（mm）

| 项目 | 数值 | 说明 |
|---|---|---|
| 盖板外径 | Φ100 | |
| 盖板厚 | 12 | |
| 总长 | 22 | 含止口，止口长 10 |
| 止口外径 | Φ62 f7 | 与座孔配合；止口端部外圆倒角 C1 |
| 通孔 | Φ36 H9 | 外端面孔口倒角 C1 |
| 密封槽 | 槽径 Φ44，槽宽 5，槽口距外端面 4 | 孔内矩形槽 |
| 安装孔 | 4×Φ9 | 通孔，均布在 Φ80 圆周上，其中一个在正上方 |

## 要求

- 止口轴线为基准 A。通孔对 A 同轴度 Φ0.05；盖板背面（贴座面）对 A 垂直度 0.04；安装孔相对 A 位置度 Φ0.2。
- 粗糙度：止口外圆 Ra1.6；盖板背面 Ra3.2；其余 Ra12.5。
- 技术要求：铸件不得有砂眼、气孔、裂纹；未注倒角 C1；未注尺寸公差按 GB/T 1804-m。
- 图幅 A3，比例 1:1，标题栏：名称“轴承透盖”，图号 LC-BC-01，材料 HT200。
