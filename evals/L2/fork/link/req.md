# 连杆

## 功能
传递往复运动的连杆：大头孔 Φ24H7 套在曲柄销上，小头孔 Φ12H7 装活动销，两孔轴线平行。杆身是平板，正面有一条加强筋。铸件。

## 形状与尺寸（mm，孔轴线沿 Y）
| 部分 | 尺寸 | 说明 |
|---|---|---|
| 大头 | 外径 Φ44，长 24，孔 Φ24H7 | 孔轴线是基准 A |
| 小头 | 外径 Φ28，长 18，孔 Φ12H7 | 两孔中心距 100 |
| 杆身 | 厚 8，轮廓是两圆的外公切线 | 圆弧连接：切线与两圆相切，切点不标尺寸 |
| 加强筋 | 宽 6，高 3，在杆身正面（-Y 侧）中线上 | 从大头圆柱面到小头圆柱面 |

## 技术要求
- 小头孔轴线对 A 的平行度 0.05；两孔 Ra 1.6，大头端面 Ra 3.2，其余 Ra 12.5。
- 铸件不得有砂眼、气孔、裂纹；时效处理；未注铸造圆角 R3~R5；未注尺寸公差按 GB/T 1804-m。

## 图纸要求
- 一张 A3、1:1。主视图孔轴线垂直于图面，表达两头和杆身轮廓；俯视图表达各段厚度和加强筋；左视图只剩大头外形，其余画虚线；杆身中部用移出断面 B-B（T 形）并标厚度、筋宽和筋高。
- 标全部定形尺寸、中心距、总长、配合公差、形位公差、粗糙度、技术要求和标题栏。
