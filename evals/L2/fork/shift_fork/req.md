# 拨叉

## 功能
变速机构的拨叉：套筒的 Φ22H7 孔套在拨叉轴上，叉口槽 24H12 卡住滑移齿轮的拨动环，臂把两者连起来，靠叉口两侧面带动齿轮轴向滑移。铸件。

## 形状与尺寸（mm，孔轴线沿 Y，叉口开口朝 +X）
| 部分 | 尺寸 | 说明 |
|---|---|---|
| 套筒 | 外径 Φ40，长 36，孔 Φ22H7 通 | 孔轴线是基准 A |
| 臂 | 厚 12，宽 28 | 从套筒伸出，到距孔轴线 62 处与叉口相接 |
| 叉口 | 厚 24，高 44，自 x = 62 到端面 x = 100 | 孔轴线到叉口端面 100 |
| 叉口槽 | 宽 24H12，贯通厚度，槽底为半圆，圆心距孔轴线 88 | 开口朝右；槽对 A 的对称度 0.1 |

## 技术要求
- 孔 Ra 1.6，叉口槽两侧面 Ra 3.2，其余 Ra 12.5。
- 铸件不得有砂眼、气孔、裂纹；时效处理；未注铸造圆角 R3~R5；未注尺寸公差按 GB/T 1804-m。

## 图纸要求
- 一张 A3、1:1。主视图按工作位置、孔轴线垂直于图面，表达套筒、臂和叉口槽；俯视图沿孔轴线全剖（过臂和槽的对称面）；左视图补厚度关系（不可见孔和槽画虚线）。
- 臂的断面用移出断面 C-C 表达并标厚度和宽度。标全部定形、定位尺寸（孔径、槽宽、中心距、总长）、配合公差、形位公差、粗糙度、技术要求和标题栏。
