# 轴承座（HT200 铸件，3D 来源）

**用途**：单个滚动轴承的座，轴线水平。底板螺栓固定，圆筒形座体内装轴承，两端沉孔装密封圈，顶部油孔加油。座体下面用一块竖向肋板与底板相连。模型见 `model.py`（轴承孔轴线 = Y 方向，原点在底面中心）。

## 形状与尺寸（mm）

| 项目 | 数值 | 说明 |
|---|---|---|
| 底板 | 120 × 80 × 14 | 4×Φ13 安装孔，位置 90 × 56（对称于中心线） |
| 轴承孔 | Φ40 H7，贯通，座体长 64 | 内壁 Ra1.6 |
| 座体外圆 | Φ64，轴线离底面 60 | |
| 两端沉孔 | Φ46，深 3 | |
| 肋板 | 厚 10，位于对称面内，从底板上表面到座体底部，长同座体 | 纵剖时不画剖面线（GB/T 4458.6） |
| 油孔 | Φ8，顶部凸台 Φ18 高 4 | 通入轴承孔 |

## 要求

- 技术要求：铸件不得有砂眼、裂纹；未注铸造圆角 R3~R5；时效处理；未注尺寸公差按 GB/T 1804-m。
- 图幅 A3，比例 1:1，标题栏：名称“轴承座”，图号 LC-BS-01，材料 HT200。
