# 阀体（ZG230-450 铸件，3D 来源）

**用途**：截止阀的阀体。介质沿水平通道流过，两端管口法兰接管，顶部阀盖法兰装阀盖，阀杆从中间孔穿出，顶部沉孔装填料。模型见 `model.py`（通道轴线 = X 轴，原点在轴线中点）。

## 形状与尺寸（mm）

| 项目 | 数值 | 说明 |
|---|---|---|
| 总长（两端法兰外面） | 100 | |
| 阀体外径 / 通道直径 | Φ44 / Φ28 H11 | 通道内壁 Ra3.2 |
| 管口法兰 | Φ76 × 10 厚，4×Φ9 | 孔均布在 Φ58 圆周上，水平、竖直方向各一个 |
| 阀颈 | Φ40，阀盖法兰顶面离轴线 56 | |
| 阀盖法兰 | Φ64 × 8 厚，4×Φ7 | 孔均布在 Φ50 圆周上，跨过中心线 45° |
| 阀杆孔 / 填料函孔 | Φ22 H8 / Φ30，深 8 | 阀杆孔向下穿入通道 |

## 要求

- 技术要求：铸件不得有砂眼、气孔、裂纹；未注铸造圆角 R3~R5；水压试验 1.5 MPa；未注尺寸公差按 GB/T 1804-m。
- 图幅 A3，比例 1:1，标题栏：名称“阀体”，图号 LC-VB-01，材料 ZG230-450。
