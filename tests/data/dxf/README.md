## Third-party file made by other CAD software: not included

The card asks for one DXF produced by another CAD program with a clear permissive license (the
ezdxf repository, MIT, is the suggested source). None is checked in:

- the installed ezdxf wheel ships no `.dxf` files, and no other DXF was found on the development
  machine or in this repository;
- fetching one from the ezdxf GitHub repository means downloading a file from the network, which the
  S4 session was not authorised to do on its own.

To add it: pick a small (< 200 KB) sample from the ezdxf repository (for example under
`integration_tests/` or `examples_dxf/` at a pinned release tag), copy it here unchanged, and record
below the exact path, the tag or commit, and the MIT license text reference. Then run
`lcad inspect` on it and add a test next to `test_import_builds_without_errors` that imports it with
`lcad init --from-dxf` and expects `errors == 0`.
