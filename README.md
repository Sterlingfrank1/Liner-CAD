# Liner-CAD

**v0.1（开发中）** · 通用 2D 工程图 Harness 层：包名 `linercad`，命令行 `lcad`。

Liner-CAD 本身不是 Agent。推理、理解需求、写代码交给宿主 Coding Agent（Claude Code / Codex / OpenCode / WorkBuddy …）；Harness 提供语义化图纸模型、脚本运行时、制图与制造约束检查、交互 Viewer 和基于 git 的版本管理。
