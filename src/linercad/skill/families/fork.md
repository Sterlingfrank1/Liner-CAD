# 叉架类（拨叉、连杆、支架、托架、叉形接头）

**适用**：由安装部分（底板、轴孔套）、工作部分（叉口、凸台、轴承孔）和连接部分（臂、杆身、肋板）组成的不规则零件，多为铸、锻件。没有回转体工具：用 `polygon / polyline / line / arc / circle` 按 `d.params` 的参数算坐标画（切点用 `math` 求），不要硬编数字。

## 主视图
按**工作位置**放；工作位置不定或倾斜的按**自然位置**（底板朝下）。让主要孔的**轴线垂直于主视图**，孔显示成圆；先画底板、孔套、叉口等基本形体，再用局部表达补形状。

## 视图 / 剖视方案
- **局部视图**只画需要表达的部分；**斜视图**表达倾斜面真形：`d.oblique("B", parent=, at=, look=)` 的箭头垂直于倾斜面，几何用 `rect / polygon` 按真长画。倾斜面在三视图里是缩小变形的，窗口、孔的尺寸注在斜视图上。
- 臂、杆身、肋板的断面形状用**移出断面**（`d.removed_section`，T 形、矩形照实画再 `hatch`）；孔、槽用**局部剖**（`v.wavy` + `v.hatch`，孔壁画粗实线，波浪线不与轮廓重合）；对称件内外都要表达时沿对称面**全剖**，螺孔用 `tapped_hole` 并把 `F.<视图>.<孔>` 当 `hatch` 的孤岛。
- **肋板纵剖不画剖面线**（GB/T 4458.6）：肋板画成自己的 `polygon`（与邻接面的分界线保留粗实线），`hatch` 只给被切到的壁和底板；肋板被横切（移出断面）才画剖面线。
- 孔在不反映圆的视图里画细虚线 + `centerline`，剖视图里已表达清楚的不再画虚线。
- 铸造圆角（R3~R5）不逐个画，写进技术要求；相切处不画线，相交处画交线（过渡线才用 `role="thin"`，与轮廓线不接触）。

## 尺寸基准与标注
- 基准：**安装底面**（高度、底板孔）、**主要孔的轴线**（孔距、孔到安装面）、**对称面**（宽度方向）。`front.datum("A", ref="D.<孔径>")`。
- 定位尺寸从基准注起（`role="position"` + `datum=`）：孔中心距、孔到安装面、叉口槽底圆心到孔轴线；孔径、槽宽是定形尺寸。肋板厚度标在反映厚度的视图或断面里，高度、位置从底板或孔轴线注。
- **圆弧连接**：已知弧给 R / Φ 和中心距，连接弧只给半径，相切的切点和直线不标；两圆外公切线只标两圆直径和中心距。半圆端（槽底、叉口）标宽度，不再标半径。
- 斜板：板厚用 `dim.aligned`，倾角 `dim.angle`（需一条延长线 `role="thin"`）；配合孔 H7、叉口槽 H12 写 `tol=` 并标粗糙度，孔轴线平行度、叉口对称度、端面垂直度用 `gtol`。

## 常见技术要求
铸件：时效处理；不得有砂眼、气孔、裂纹；未注铸造圆角 R3~R5；`d.rough_default(12.5)`。锻件：调质 / 正火 + 硬度；未注圆角 R1~R2。`d.general_tol("m")`。

## 常见错误
1. 肋板纵剖画了剖面线，或漏掉肋板与底板、凸台之间的分界粗线。
2. 主视图孔轴线平行于图面，孔全靠虚线表达，读不清。
3. 倾斜面没有斜视图，窗口、孔的真形尺寸量不到。
4. 孔的定位尺寸链式累积、没有 `datum`，或把孔中心距标成孔边距。
5. 逐个画小圆角；半圆端既标半径又标宽度；相切处画了粗线。
6. 局部剖的波浪线压在轮廓线上或穿过孔；剖视图里又重复画孔虚线。
7. 断面字母与基准字母重名（基准用 A、B，断面从 C 起）；PMI 引出线穿过材料：`gtol / rough` 默认朝远离视图中心一侧，斜面外侧要用 `.move(dx=, dy=)` 拉出。

## 工具
`v.polygon / polyline / line / arc / circle / center_mark / centerline / wavy / hatch`、`v.tapped_hole`、`v.thread_end`、`d.section`、`d.removed_section`、`d.oblique`；`dim.linear / dia / rad / aligned / angle / hole`、`datum / gtol / rough`。有 3D 模型时用 `d.model` + `view.project`，见 `lcad skill 3d`。

## 范例
`lcad init <目录> --from shift_fork`（拨叉：孔轴线垂直图面、俯视全剖、臂的移出断面）· `--from bearing_support`（轴承支架：局部剖底板孔、左视全剖肋板不画剖面线）· `--from bracket`（L 形支架三视图）
