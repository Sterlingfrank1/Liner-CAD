# 盘盖类（端盖、轴承盖、法兰盘、带轮、齿轮坯、手轮）

**适用**：轴向尺寸小于径向尺寸的回转体，常带均布孔 / 螺孔、止口、轮毂和键槽。先用 `turned` 画外形，不要手拼 polygon 和剖面线。

## 主视图
轴线水平（车削位置），主视图画剖视，轴线 = 模型 X 轴；**左视图**看有孔 / 螺孔 / 安装面的那一端。端视图里只画看得见的圆，背后的凸台、止口不画虚线。

## 视图与剖视方案
- 内部结构简单（孔、台阶、螺孔）→ 全剖 `turned(cut="full")` + 端视图；零件对称又要保留外形（带轮、齿轮坯）→ 半剖 `cut="half"`。
- 剖切符号放在端视图：`d.section(..., through=[(0,-R),(0,R)])`。剖切面过孔轴线：偶数个孔 `start=90` 时上下两个都被剖到，奇数个只剖到上方一个，**照实画，不要画不在剖切面上的孔**。
- 孔都不在轴线平面上、或孔分在不同平面：相交面用旋转剖（`through` 折线，把孔转到剖切面上画），平行面用阶梯剖。均布孔只画一个，用 `n×` 注数量。
- 腹板两侧凹进是环形槽：用 `holes`（r = 槽中径，d = 槽宽）表示，并把它自动生成的孔中心线 suppress。
- 局部细节（V 槽、密封槽）能用尺寸说清就不另加视图。

## 尺寸基准与标注
- **径向基准是配合孔的轴线**：`front.datum("A", ref="D.<孔径>")`；盘厚、总长、凸台 / 止口长从**安装端面**注起，链式标，末段不标，总长另起一排或用参考尺寸。
- 直径标在剖视图的非圆轮廓上；端视图只标均布孔（`n×Φd EQS`）和节圆。
- 配合面（孔 H7、止口 h8 / f7）写 `tol=` 并标粗糙度；孔与止口的同轴、端面对孔轴线的垂直 / 跳动、孔组位置度用 `gtol` 关联到尺寸或边。
- 螺孔：端视图 `thread_end` + `dim.hole`（代号），螺纹深和钻孔深在剖视图上另注；钻孔锥角 120° 由 `tip` 给出，深度算到圆柱部分末端。
- 轮毂键槽：`turned(hub_keyway=True)` + `keyway_end`，宽 JS9、深 d+t2 由 `res.key` 给出，用 `dim.keyway` 标。
- 倒角：标一个，其余写进技术要求“未注倒角”；铸件加铸造圆角说明。

## 常见技术要求
铸件：时效处理；不得有砂眼、气孔、裂纹；未注倒角 / 铸造圆角。钢件：调质 / 正火 + 硬度。`d.rough_default` 取铸造面 Ra12.5（机加工为主取 6.3）；`d.general_tol("m")`。

## 常见错误
1. 手画剖面线或把螺栓孔画成断开的矩形（应 `turned(cut=..., holes=...)`）。
2. 螺孔画成光孔，缺大径细线 / 终止线；端视图螺孔用粗圆代替 `thread_end`。
3. 均布孔没有节圆直径、没有 `n×` 和 EQS；孔标在非圆视图的虚线上。
4. 配合孔没有粗糙度；基准字母没定义就用；跳动、垂直度基准选在非配合面。
5. 轴向尺寸注成封闭链（总长 + 全部分段）。
6. 孔深没有注，或孔深起点不是开口端面。
7. 键槽只标宽、不标深；半剖里下半也画了剖面线。

## 工具
`v.turned(cut, half, bore, holes, hub_keyway)` `v.thread_end` `v.holes_on_circle` `v.center_mark` `v.keyway_end`
`d.section` `dim.dia / linear / chamfer / hole / keyway` `v.datum` `v.gtol` `v.rough` `d.rough_default` `d.general_tol` `res.fit / thread / key`

## 范例
`lcad init <目录> --from flange`（全剖 + 4 孔 + H7，配合面 PMI）· `--from end_cover`（止口、阶梯孔、3×M8 螺孔、3 个均布孔只剖到一个）· `--from pulley`（V 槽轮缘、腹板凹进、轮毂键槽）
