# 轴套类零件卡片

**适用**：阶梯轴、齿轮轴、花键轴、丝杠、套筒、衬套、隔套。只写判断；规定画法的数值和对错由工具与 `lcad check` 负责。

## 主视图
- 轴线水平（车削加工位置）。螺纹、花键等特征多的一端放左，键槽朝向观察者。
- 轴类一个主视图就够；套类用剖视（见下）。不要为了“完整”加俯视图。

## 视图 / 剖视方案
- **实心轴**：外形不剖。键槽用移出断面（`d.removed_section` + `sec.shaft_cut`），不在主视图里剖；退刀槽、砂轮越程槽用局部放大（`d.detail`，5:1 或 4:1）；花键给端面视图（`spline_end`）。
- **套筒、衬套**：内外都要表达，对称零件用半剖（`turned(..., cut="half")`）；只关心内孔时用全剖（`cut="full"`）。孔的倒角、内槽写在 `bore` 轮廓里。
- 断面和局部放大放在主视图下方或右侧的空位，用 `place(at=)` 指定（`at` 是视图坐标原点，不是图形中心）；主视图两端的中心孔、倒角引线要留地方，必要时 `front.move(dx=)`。

## 尺寸基准与标注
- 径向基准是轴线；轴向基准选功能面（装齿轮、轴承的轴肩），不要用毛坯端面。
- 直径标在各段中部（`side="inside"`），有配合的段带公差代号（`tol="k6"`）；太窄的轴肩把直径放到相邻的宽段位置。
- 轴向长度链式标在下方，**留最不重要的一段不注**（最右一段常用），总长另起一排；螺纹长度（到退刀槽）、键槽长度和位置标在上方。
- 键槽：宽 b 和深 d−t1 标在断面上，长度和起点位置标在主视图；螺纹标代号（外螺纹不标小径）；退刀槽标“槽宽×直径”；倒角、中心孔用代号，不画尺寸线。
- 公差基准用两个支承轴颈的公共轴线（A-B）；跳动给配合面（齿轮段、轴头、花键外圆）。同轴度、垂直度的基准取与之配合的轴线或端面。

## 常见技术要求
- 热处理（调质、淬火及硬度）；未注倒角、圆角；中心孔加工后保留；未注尺寸公差按 GB/T 1804-m（`d.general_tol("m")`）。
- 粗糙度：配合轴颈最细，端面和台阶面次之，其余用通用符号（`d.rough_default`）；先标配合面再标其余。

## 常见错误
1. 键槽在主视图里剖开，或键槽朝向与断面不一致。
2. 轴向尺寸首尾封闭（每段都标 + 总长）。
3. 配合轴颈只标公差、没标粗糙度；基准和跳动落在非配合面上。
4. 螺纹只标直径、不标代号；退刀槽不标；螺纹长度含了退刀槽。
5. 套类半剖里把外圆和内孔的配合都写在一个尺寸上；两端内孔倒角漏标。
6. 辅助视图压在主视图尺寸上：先 `lcad render` 看，再用 `place` / `move` 挪。

## 用到的工具
`v.turned`（`bore` `cut` `grooves`）、`v.thread`、`v.center_hole`、`v.keyway`、`v.spline`、`v.spline_end`、`d.removed_section`、`sec.shaft_cut`、`d.detail`；标注 `dim.dia` `dim.linear` `dim.thread` `dim.groove` `dim.keyway` `dim.spline` `dim.chamfer`；PMI `datum` `gtol` `rough` `d.rough_default` `d.general_tol`。

## 范例（`lcad init <目录> --from <名>`）
- `shaft`：减速器输出轴——外螺纹 + 退刀槽（局部放大）、键槽 + 移出断面、中心孔、k6 / n6 配合、跳动、粗糙度。
- `sleeve`：带肩衬套——半剖、r6 / H7 配合、同轴度、垂直度。
- `spline_shaft`：花键轴——轴向视图 + 端面视图、花键代号、轴颈基准 A-B 与圆跳动。
