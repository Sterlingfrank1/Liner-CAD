# 3D 来源：由模型投影出视图

需要可选依赖：`uv add "linercad[3d]"`（build123d）。没装时报 `missing_extra`。

## 模型

图纸目录里放 `model.py`（或 `.step/.stp`）：

```python
from build123d import Box, Cylinder, Pos

def model(L=150, W=110, t=10, d=28):          # 关键字参数 = 图纸参数名（float），返回实体
    body = Pos(0, 0, t / 2) * Box(L, W, t)
    return body - Pos(0, 0, t / 2) * Cylinder(d / 2, t + 2)
```

模型轴：X 右、Y 向后、Z 向上；主视 (X, Z)，俯视 (X, Y)，左视 (−Y, Z)。原点放在对称面上，剖切才方便。
参数只用图纸里 `d.params` 声明的名字；`range()` 前先 `int()`；Builder 模式返回 `part.part`。

## drawing.py

```python
d.model("model.py")                                # → M.main（路径相对图纸目录；model.py 会一起提交）
front = d.view("front")
front.project(cut="full")                          # 全剖：沿过原点、垂直投射方向的面剖开，自动剖面线 H.front.model
d.view("top").project(hidden=False)                # 外形，不画虚线
d.view("left").project(cut="half", half="right")   # 半剖：剖开右半（left/right 以竖直轴分，top/bottom 以水平轴分）
d.view("top").project(name="loc", region=[(30, -40), (70, -40), (70, -20), (30, -20)], depth=6)
                                                   # 局部剖：只在 region（视图坐标）内剖开，边界自动画波浪线
front.project(cut="full", ribs=[[(x0, y0), (x1, y0), (x1, y1), (x0, y1)]])   # 肋板纵剖不画剖面线
```

- `depth`：剖切面离模型原点、朝观察者方向的距离（切空会报错并给出 range）。
- 投影边是特征 `F.<视图>.<name>` 的子边 `E.<视图>.<name>.<k>`：直线 / 圆 / 圆弧保留类型；可见边粗实线，虚线 `hidden`，相切光滑边细实线（`conv` 标签，过渡线）；样条等近似成短线（`approx` 标签）。
- 每条边带 `intent.src3d`（来自模型哪条边、相邻哪些面、几何哈希）；尺寸 / 形位公差 / 基准引用这些边时自动记 `src3d_refs`。
- **模型改了边号可能变**：标注引用投影边时用查询或坐标，不要写死 `E.front.model.17`：

```python
hole = d.q.circles(view="top", r=P.d.value / 2).first()
top.dim.dia("d", circle=hole, value=P.d, tol="H7")
top.dim.linear("A", (-P.A / 2, -P.B / 2), (P.A / 2, -P.B / 2), value=P.A, side="bottom")
```

- 中心线、对称线、中心符号投影里没有，自己加（`v.centerline` / `v.center_mark`）；定位尺寸的 `datum` 可以是这些中心线。
- 投影结果缓存在 `.linercad/cache/`，参数或模型不变时重建很快。
- 3D 来源目前不做阶梯 / 旋转剖与移出断面：这些用 2D 画法（`d.section`、`d.removed_section`）补。

范例：`lcad init <目录> --from gear_cover`（箱体，几何全部来自模型）。
